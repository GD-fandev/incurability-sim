# 무불 시뮬레이터 / 永久不治シミュ

최대 MP·SP와 MEN·VIT를 입력하면 회복 액세서리 0~3개별 불치의 노래 예상 지속시간과 무한 유지 여부를 표시합니다.

## 사용법

- `index.html`을 브라우저에서 열거나 배포된 페이지에 접속합니다.
- 게임 상태창의 최대 MP·SP와 MEN·VIT를 정수로 입력하면 결과가 자동으로 갱신됩니다.
- VIT·MEN 30의 최소선 예제는 `적용` 버튼으로 입력할 수 있습니다.
- 우측 상단의 `KR` / `JP`로 언어를 전환합니다.

게임 화면에 표시되지 않는 소수점과 반올림 처리에 따라 실제 지속시간은 예상값과 다를 수 있습니다. 무한 유지 예상은 참고용으로 확인해주세요.

## 使い方

最大MP・SPとMEN・VITを入力すると、回復アクセ0～3点ごとの不治の歌の予想持続時間と永久維持の見込みを表示します。

- `index.html`をブラウザーで開くか、公開ページにアクセスしてください。
- ゲームのステータス画面に表示される最大MP・SPとMEN・VITを整数で入力すると、結果が自動更新されます。
- VIT・MEN 30の最低ラインは「適用」ボタンで入力できます。
- 右上の `KR` / `JP` で言語を切り替えられます。

ゲーム画面に表示されない小数点以下の値や端数処理により、実際の持続時間は予想値と異なる場合があります。永久維持の見込みは参考としてご利用ください。
